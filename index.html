🎮

أوفرلي شفاف بأسلوب PS5

قائمة زجاجية شفافة باللون الأزرق الداكن والبنفسجي المضيء مع أنيميشن ناعم تظهر فوق أي لعبة بالضغط على F8 أو Alt + Z (وتتكيف تلقائياً إذا كان الاختصار محجوزاً).

⏪

حفظ آخر 15ث حتى 10 دقائق

مخزن دائري ذكي بتقنية DXGI + NVENC Zero-Copy (مع دعم AMD AMF و Intel QSV) يحفظ لقطاتك بدقة أصلية وبـ 30/60/120 FPS بدون تعليق للماوس أو سحب من الرام.

🎚️

3 قنوات صوت مستقلة + دبل ×2

يسجل صوت اللعبة والويندوز، ويكتشف تلقائياً قناة صوت خويك بالديسكورد (SteelSeries Sonar - Chat / المكالمات) مع زر كتم فوري، والمايك اختياري مع سلايدر 0–300% ودبل ×2 بدون تشويش.

⚡

مخفف عمليات المعالج الذكي

يعرض كل عملية بأيقونتها ومسارها الكامل مع مستشار ذكي ينصحك بما يُغلق وقت اللعب، وحماية كاملة لملفات ويندوز الحرجة، مع وضع Eco Mode وإغلاق كل نسخ المتصفح بضغطة.

🛡️

حماية مكالمة الديسكورد

خيار «لا تطفي الديسكورد» موجود مباشرة تحت زر التخفيف — يبقيك في المكالمة مع أخوياك ويخفف أولويته فقط، ولو شلت الصح يغلقه مع باقي التطبيقات فوراً.

🚀

حفظ تلقائي + تشغيل مع ويندوز

كل إعداداتك (الفريمات، الدقة، الصوت، قائمة الاستثناء) تُحفظ تلقائياً في نسختين آمنتين، مع خيار Startup ليقلع التطبيق بصمت بجانب الساعة فور تشغيل الكمبيوتر.
